# v0.5 Advanced Discovery & Intelligence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the verified v0.4 engine with richer TLS, HTML, authentication, security-control correlation, Markdown reporting, and safe non-interactive scanning.

**Architecture:** Preserve the existing `ScanEngine -> ModuleRegistry -> ModuleResult -> ScanSession` flow. Modules consume one bounded network observation; evidence and findings are deterministic and sanitized before reporting. New report and CLI capabilities are additive.

**Tech Stack:** Python 3.11–3.14, Python standard library, pytest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-17-v0.5-advanced-discovery-intelligence-design.md`

## Global Constraints

- HTTP/HTTPS only.
- GET only; no credentials, custom cookies, request bodies, login automation, token harvesting, password attacks, exploitation, persistence, destructive actions, or arbitrary-range scanning.
- Public HTML is parsed only from the bounded response already collected.
- Discovered links are metadata only and are never automatically requested.
- Cookie values, form values, and sensitive query strings never enter evidence or reports.
- Response size, redirects, timeout, and total scan budgets remain bounded.
